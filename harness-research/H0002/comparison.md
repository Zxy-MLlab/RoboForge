# Comparison

## H0001

Consequential prerequisites existed only in internal Tool metadata and runtime
dispatch. Models discovered them through rejection or remembered prompt
conventions.

## H0002

The same prerequisite is visible next to each affected function contract.
Read-only and validation Tools remain concise and need no Decision Record.

This iteration changes one interface variable only. It does not combine
Decision recording with execution or weaken provenance requirements.

Two paired generic autonomous runs reduced observed missing-Decision rejection
rate from 17.2% to 4.3%. Total errors also fell from 12 to 9, while physical
trials increased from 1 to 2. The sample is small and stochastic, so this is
evidence for reduced interaction friction, not a performance guarantee.
