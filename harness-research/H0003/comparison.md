## H0003

Both execution modes truthfully state the same source and entrypoint contract.

The paired run changed diagnostic conversion from 0/2 to 1/1 and allowed the
candidate to reach a physical trial. This is evidence for interface usability,
not a claim about manipulation or task success.

The later LIBERO Task 1 comparison repeated the same direction: 0/1 committed
diagnostics plus an entrypoint-failed physical trial on baseline, versus 2/2
committed diagnostics plus an action-bearing physical trial on Candidate.
LIBERO Task 2 was neutral for the entrypoint hypothesis and is not presented as
a second positive reproduction.
