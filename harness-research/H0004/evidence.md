# Evidence

The runtime accepts only references beginning with `evidence://`,
`artifact://`, or `run://`. The Tool schema previously defined
`evidence_refs.items` as a non-empty string with no pattern or explanation.

P30 had one rejected Decision attempt for this exact error. The H0002
candidate generic run then produced five consecutive invalid-reference
Decision attempts, demonstrating that consequence visibility alone did not
make the routing grammar discoverable.

Baseline regression failed because `pattern` was absent.
