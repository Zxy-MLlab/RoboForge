# OpenHands-native RoboForge

RoboForge's formal entry point is `roboforge-openhands`. It constructs an
OpenHands SDK `Agent` and `LocalConversation`; OpenHands owns the model loop,
conversation/event persistence, context, workspace, file editing and generic
tools. RoboForge contributes only embodied tools (`observe`, `run_controller`,
`inspect_trial`, `compare_trials`) and the `ExperimentService` that records
physical budgets, reset generations, immutable Controller snapshots/artifacts,
authentic Adapter receipts, provenance, crash recovery and idempotency.

The Adapter is the only authority for sensors, actions, reset, safety and
physical verification. It cannot select task strategy or forge verification.
Evaluation remains an external consumer and is never imported by the embodied
runtime. Removing `roboforge/` leaves the normal OpenHands coding agent.

Assets are stored in `experiences/`, `skills/`, and `capabilities/`. Search
returns metadata summaries only; implementation details are read explicitly,
so OpenHands context management can use progressive disclosure.

The first real LIBERO campaign at
`/root/autodl-tmp/experiments/openhands-native-task0-r4` records an unknown-task
trajectory: the Agent received the natural-language instruction, inspected the
public SDK, wrote a Controller, called RGB-D perception, and committed one
physical experiment. The receipt was authentically `verified: false`; the
result is therefore recorded as observed partial behavior rather than success.
Its reusable metadata is persisted under
`/root/autodl-tmp/experiments/openhands-native-assets/experiences/`.

## Recovery incident

During Task B resume, an interrupted physical reservation was followed by a
new OpenHands tool-call ID for the same Controller. The pre-fix service accepted
the second ID and executed again. Both the pending reservation and committed
second execution remain in the campaign ledger; this is classified H
(recovery/idempotency), not task progress. The service now blocks every new
physical action while any pending physical reservation exists, regardless of
tool-call ID. Reconciliation is external-only, requires a disposition and note,
never executes an action, and never refunds the consumed physical budget.

Run with `roboforge-openhands --adapter libero --task 0 --run-dir runs/task-0`
after installing the optional OpenHands and LIBERO dependencies and configuring
the provider key. Deterministic regression coverage is in
`tests/test_openhands_native.py`; real LIBERO evidence must be generated by the
configured deployment and reported separately from FakeAdapter tests.
