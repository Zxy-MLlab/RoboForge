# Autonomous Closed-Loop Grasp/Place Recovery

Use only fresh RGB-D/RGB observations, camera calibration, language, and robot proprioception.

1. Pass the complete live instruction to semantic source/target selection; never replace it with a truncated token list or unordered noun bag. After roles are established, extract concrete object, destination, and landmark noun phrases for open-vocabulary detection; discard authoring meta-phrases such as “source object in the clause.” Validate semantic selection before motion. Require source and destination to differ. Permit a fused source/reference region only for containment or support relations such as `in` and `on`, never for `next to` or `between`. Before motion, build a magnified contact sheet of candidate crops and run a second VLM pass with detector scores hidden. Accept its replacement region only when that region directly detects or visibly contains the first-pass movable source; otherwise preserve the physically consistent first-pass instance and log the rejected disagreement. If the accepted pass selects a large support region such as a drawer or cabinet, project it back to the most specific overlapping detection of the movable noun; never send a support-region box to the grasp generator.
2. Generate geometrically diverse ranked grasps from the segmented RGB-D point cloud. On the LIBERO Panda OSC controller, prefer `robot-topdown` until a model-oriented candidate demonstrates reachable position error below 1 cm; retain each candidate's planar yaw while replacing tilt with the calibrated vertical approach, because discarding yaw makes otherwise diverse grasps geometrically equivalent. Do not repeat a fully model-oriented setting after a complete 3/3 sensor-verified attachment failure under the same robot/controller geometry. Compute top-down orientation error in quaternion space; never subtract axis-angle vectors near π because equivalent +π/−π representations destabilize recovery. If strict 6-DoF filtering yields no candidate and the controller explicitly replaces model orientation with calibrated `robot-topdown`, permit only bounded target-local translations that still satisfy physical gripper width, non-empty finger volume, and a relaxed collision diagnostic; record this pool separately. If neither pool exists, emit a structured sensor-only frontier failure instead of crashing.
3. Execute `open approach → contact → close → lift at least 8 cm → fresh observe → verify`. Never verify at the contact pose: source-vacated is intentionally required. Keep the adapter-owned initial source baseline immutable across retries even when a failed contact moves the live target. Accept attachment only when the newly segmented object moved from that baseline, is near the EEF, the gripper is closed, and no matching detection remains near the original source position. Record candidate index, object/EEF positions, source-vacated evidence, gripper width, and phase tracking errors.
4. If attachment fails, use the new RGB-D/SAM estimate to relocalize a target that was pushed by contact, translate the remaining target-local candidates by that observed displacement, and then try the next bounded diverse candidate. Never keep executing stale world coordinates after visible object motion. Preserve failed parameter/result pairs so later authoring turns do not repeat disproven settings.
5. After a verified lift, compute the realized carried-object offset from fresh RGB-D and proprioception: `object_xyz - eef_xyz`. Reobserve once more after transfer above the destination and update this transform before descending, because an object can slip or rotate during transport. Recenter the place EEF goal from the latest observed transform; do not use the pre-contact GraspNet point as the carried transform.
6. Segment the unobstructed destination before transport and retain the returned opaque support-mask handle. After release, acquire two fresh post-settle object masks and pass the same pre-placement support handle to both relation checks. Require both checks to pass and world-position motion to remain at most 1.5 cm. Verify RGB-D height, footprint containment, and center clearance with calibrated minima of 0.55 containment and 0.25 silhouette-radius clearance. Keep world-XY center error as a diagnostic, not the sole decision: partial target visibility can bias its estimated center even when the object footprint is stably contained.
7. Stop recovery immediately when visual placement is verified. Otherwise regrasp and recenter within the declared correction budget. Apply the same orientation-compatible fallback and empty-candidate handling to correction grasps as to the initial grasp; never index an empty proposal list. Treat named correction close/release phases as timed gripper phases rather than ending them early on positional convergence. Abort rather than continue when phase tracking error makes the correction pose unreachable.

8. Preserve the strongest strictly verified program prefix across evolution rounds. Inspect the immutable best controller before editing. If evidence shows candidate zero failed and a later candidate attached, retain the bounded multi-candidate loop and modify only the first unverified suffix. Never claim a prefix was preserved without inspecting it.

Never use reward, done, check_success, BDDL, body poses, simulator segmentation IDs, demonstrations, or task/state-specific branches as recovery inputs.

The benchmark evaluator is queried once after release, retreat, and settle, solely for the final score.
